# 海面溢油检测模型改进总结

## 任务背景

模型应用于 **海面溢油检测 (Sea Surface Oil Spill Detection)**，具有以下特点：

| 特性 | 描述 |
|------|------|
| 任务类型 | 二分类（海水 / 溢油） |
| 标签不平衡 | 海水标签 : 溢油标签 ≈ **99 : 1** |
| 溢油分布 | 图中分布不均匀，存在长尾分布问题 |
| 评价指标 | Recall（召回率）、AUC |
| 损失函数 | DiceCELoss (dice_weight=0.1 + CE=0.9) |

---

## baseline22 — 基于 baseline20 的改进

### 基线回顾 (baseline20)

- UNet3Layer: base=24, heads={1,2,4,8}, priori=`torch.mean(x, dim=1, keepdim=True)`
- SnakeConvUnit + CoordAtt (Coordinate Attention) + SpatialViTBlock

### 改进点

| 改进模块 | 说明 | 针对的问题 |
|---------|------|-----------|
| **SpectralWeightedPrior** | 用可学习的 1×1 卷积融合多光谱通道生成先验图，替代简单的全局平均 | 油膜和水体在不同光谱波段有显著差异，learnable weighted sum 保留光谱鉴别信息 |
| **SEBlock** | 在 SnakeCoordAttViTBlock 输出后插入 Squeeze-and-Excitation 通道注意力 | 增强溢油相关特征通道，抑制背景噪声通道，缓解 99:1 不平衡 |
| **FocalGate** | 在 Attention Value 调制后加入可学习门控 | 让模型聚焦难分样本（溢油区域），突出硬样本梯度信号 |
| **base=26** | 基础通道数 24 → 26 | 适度增加模型容量，学习更精细的油膜特征 |

### 新增模块架构

```
SpectralWeightedPrior:
  Input: (B, C, H, W) → Conv2d 1×1 (C→C/4) → BN → ReLU → Conv2d 1×1 (C/4→1) → Output: (B, 1, H, W)

SEBlock:
  Input: (B, C, H, W) → GAP → Linear(C→C/r) → ReLU → Linear(C/r→C) → Sigmoid → Scale → Output: (B, C, H, W)

FocalGate:
  v_modulated → Linear(dim→dim) → Sigmoid → v_modulated * gate
```

### 模型参数量

- baseline20: ~1.49M
- **baseline22: ~1.83M** (+23%)

---

## baseline23 — 基于 baseline21 的改进

### 基线回顾 (baseline21)

- UNet3Layer: base=24, heads={1,2,4,8}, priori=`SobelPrior(x)`（单尺度 Sobel 边缘）
- 其余与 baseline20 相同

### 改进点

| 改进模块 | 说明 | 针对的问题 |
|---------|------|-----------|
| **MultiScaleSobelPrior** | 3×3、5×5、7×7 三种尺度 Sobel 并行提取边缘，1×1 卷积融合 | 小油斑 → 细粒度边缘 (3×3)；大油膜 → 粗粒度边界 (7×7)；适配油膜尺度多样性 |
| **DilatedSnakeConvUnit** | SnakeConvUnit 基础上引入空洞卷积，扩大感受野 | 捕获溢油上下文信息，改善长尾分布下稀疏油斑的检测 |
| **GatedSkipFusion** | 跳跃连接处门控特征融合（编码器特征×gate + 解码器特征×(1-gate)） | 自适应选择有用特征，抑制背景噪声传递，缓解不平衡 |
| **渐进式空洞** | Encoder: dilation=1,1,2,2；Decoder: dilation=2,1,1 | 深层扩大感受野捕获大范围上下文，浅层保持精细定位 |

### 新增模块架构

```
MultiScaleSobelPrior:
  Input: (B, C, H, W) → Mean(dim=1)
  ├─ Sobel 3×3 → edge3
  ├─ Sobel 5×5 → edge5
  └─ Sobel 7×7 → edge7
  → Concat(edge3, edge5, edge7) → Conv2d 1×1 (3→1) → Output: (B, 1, H, W)

DilatedSnakeConvUnit:
  与 SnakeConvUnit 相同结构，但 Conv2d 增加 dilation 参数

GatedSkipFusion:
  gate = Sigmoid(Conv1×1(enc) + Conv1×1(dec))
  output = enc × gate + dec × (1 - gate)
```

### 模型参数量

- baseline21: ~1.49M
- **baseline23: ~1.57M** (+5%)

---

## 改进策略对比

| 维度 | baseline22 | baseline23 |
|------|-----------|-----------|
| 设计哲学 | 光谱鉴别 + 通道重标定 + 难分样本聚焦 | 多尺度边缘 + 感受野扩张 + 门控特征选择 |
| 先验图 | 可学习光谱加权 (Learned Spectral) | 多尺度 Sobel 融合 (Multi-scale Edge) |
| 核心机制 | SE Channel Attention + Focal Gate | Dilated Convolution + Gated Skip Fusion |
| 参数增量 | +23% (1.49M → 1.83M) | +5% (1.49M → 1.57M) |
| 适用场景 | 光谱特征差异明显的数据集 | 油膜形态多样、尺度变化大的数据集 |

---

## 使用方式

在 `IP_train.py` 中将 `TRAIN_MODELS` 改为对应模型名即可训练：

```python
TRAIN_MODELS = ["baseline22"]   # 或 "baseline23"
```

训练命令与现有流程完全兼容，无需修改任何已有文件。
