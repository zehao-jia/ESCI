# 创新
- 抓住HS-MS融合的核心痛点-模态信息割裂,局部注意力视野受限,光谱通道权重失衡
# 现有痛点
- CNN感受野有限
- 注意力机制无法充分整合两种模态的信息,忽略关键波段的相关性
# 核心架构
- MIAN是一个端到端的HS-MS图像融合框架

## 关键模块
![[屏幕截图 2026-03-17 230932.png]]
- swin transformer块的常见架构
- 标准 Transformer Encoder 用**全局注意力**做序列建模，Token 数固定、单尺度；Swin Transformer Block 用**窗口 + 移位窗口注意力**做视觉建模，**层级下采样 + 多尺度特征**，计算更高效、更适配图像

# 实验
- 在所有数据集和尺度下取得最优或次优结果
- **在视觉效果上**
- 伪彩色图像和误差图中亮白色伪影区少,说明与真值的差异小
- 单波段可视化下残差图伪影更小
- 热图分析下绝对误差热图更偏蓝色,表明误差显著低于其他办法
- 重建的光谱曲线与真实值几乎重合
