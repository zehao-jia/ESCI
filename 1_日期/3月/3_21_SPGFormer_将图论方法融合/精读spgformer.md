# 摘要
摘要-结合图结构表示和自注意机制，图Transformer（GT）通过同时建模复杂的拓扑结构和捕获长距离光谱，在高光谱图像（HSI）分类中表现出显著的有效性，当前的GT模型难以有效地将节点特征与位置信息集成，同时平衡全局位置上下文和局部结构关系。针对这些挑战，本文提出了一种结构感知GT具体地，SPGFormer引入了双分支交互式Transformer（DBIT）模块，其通过节点特征Transformer（NFT）分支和结构感知位置Transformer（SPPT）分支并行处理节点谱特征和拉普拉斯位置信息，NFT分支采用Transformer编码器对谱特征进行建模，SPPT分支利用图拉普拉斯特征向量捕获全局位置信息。此外，提出了一种结构感知多头自注意（SPMHSA）机制，将局部拓扑结构信息集成到SPPT分支中。此外，为了促进这些互补特征空间之间的有效交互，提出了双向交叉注意模块（BCAM）来实现这两个分支之间的双向通信。综合实验结果表明，SPGFormer在多个指标上优于现有的最先进（SOTA）方法，包括总体准确性（OA），平均准确度（AA）和Kappa系数，在四个基准HSI数据集上，OA分别提高了2.04%、2.39%、1.10%和2.27%。

# 方法论
## DBIT
- 两个分支的交互:q矩阵与k,v矩阵来自不同分支
- **双分支架构**:
  - 该架构主要包含两个分支：
    - **节点特征变换器（NFT）**: 使用多个标准transformer处理光谱特征。
    - **结构感知位置变换器（SPPT）**: 利用拉普拉斯特征向量来建模全局位置信息。
    

- **机制**:
  - **结构感知多头自注意力（SPMHSA）**: 将k-hop局部结构信息与标准自注意力相结合，使模型能够同时识别局部连接和全局位置信息。
  - **双向交叉注意力模块（BCAM）**: 促进NFT和SPPT分支之间的交互,光谱特征指导pe的细化,结构信息增强光谱的特征表示
  - 最终,为了从超像素级表示过度到像素级表示,集成了基于dwconv的cnn单元,将其与DBIT模块得到的图进行智能融合
## 图的构造与特征转换
- 1.超像素分割:将hsi表示为图形结构克服了规则网格表示的局限性,允许灵活的建模不同土地覆盖之间的临接,相似和连接模式,超像素的个数$z = \frac{h\times w}{\lambda}$,$\lambda$为超参数,超像素的引入将原始像素网络变为空间相干超像素,其中的每个像素包含着有相似光谱特征的像素
- 2.无向图构建:构造一个无向图$G = (V;E)$,V表示超像素的集合,E表示超像素的边,对于每个超像素,通过平均包含在其中的所有像素来计算节点特征:$$F_{i} = \frac{1}{n_{i}}\sum_{j=1}^{n_{i}}X_{i}^j$$其中,f表示超像素节点的特征向量,x是包含其中的像素,如果两个超像素相邻,就通过高斯核函数计算边的权重$$W_{i,j} = \exp(-\frac{||F_{i}-F_{j}||^2}{\sigma^2})$$
- 3.超像素和像素的转换:P2S解码器和S2P解码器 
## SPPT分支
- 该模块由三个部分组成:laplacian PE,k-hop和局部结构嵌入SPMHSA
### 拉普拉斯位置编码
- 1.基于加权邻接矩阵构建图拉普拉斯矩阵$$L = I-D^{-\frac{1}{2}}WD^{-\frac{1}{2}}$$
- 其中,I为单位阵,D为度矩阵$D_{ii} = \sum_{j}W_{ij}$
- 随后,对矩阵进行特征值分解$$L = U\lambda U^T$$其中,$\lambda$是一个对角阵,包括所有特征值从小到大排列,最小值为0所以从第二个开始取$\lambda = diag(\lambda_{1},\lambda_{2}\dots \lambda z)$其中z是超像素的个数
>虽然特征分解通常具有O（$z^3$）的计算复杂度，但由于超像素图的局部连通性，拉普拉斯矩阵L表现出稀疏性。更重要的是，由于PE仅需要前m个最小特征向量，因此可以采用高效的稀疏部分特征分解来显着减少计算负担。从谱图理论的角度来看，图拉普拉斯特征向量为图上定义的函数提供了自然基础，其中较低频率的特征向量（对应于较小的特征值）捕获全局平滑变化，而较高频率的特征向量编码局部结构细节。该特性特别适合于HSI，其中空间上相邻的像素通常属于相同的土地覆盖类，而不同材料之间的边界会产生局部不连续性。与假定固定网格坐标的绝对PE或缺乏结构意义的随机PE不同，Laplacian PE固有地编码HSI图结构中的连通性模式和相似性关系，使其特别适合于保持空间-谱拓扑

- $ 优点:基于拉普拉斯特征向量的位置信息来自图本身的拓扑结构,自然地结合了hsi的内在空间关联模式和全局结构信息
### k-hop局部结构
- & 目的:建模节点的多尺度局部拓扑结构
- 方式:给定一个临接矩阵W,通过深度优先搜索,构造k-hop矩阵,对于每个节点v,DFS会找到k步到达其他节点的所有路径
- $$A_{k}(v,v_{k})=\frac{1}{k}(W(v,v_{1}),\dots W(v_{k-1},v_{k}))$$ $$s^{(1)}=A_{1},S^{(2)}=A_2\dots$$
其中$v_{1}$表示经过的第一个节点,当存在多条路径时,就构建多个A
- $ 优点:扩展单个节点的接受域,使其与更多节点建立连接,并将这些k-hop临接矩阵作为信息结构矩阵
