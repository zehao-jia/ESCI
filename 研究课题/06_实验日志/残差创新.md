# 残差创新

## 关键创新

### 1. 完整注意残差（Full Attention Residuals）

- **机制**：用学到的注意力权重替代固定累积，使用 **softmax** 机制在之前层的输出上进行计算。
- **公式**：\[h_l = \sum_{i=0}^{l-1} \alpha_{i \to l} \cdot v_i\]其中 \( \alpha_{i \to l} \) 是通过学习的伪查询计算的 softmax 注意力权重。
- **注意力权重计算**：
  \[
  \alpha_{i \to l} = \frac{\phi(q_l, k_i)}{\sum_{j=0}^{l-1} \phi(q_l, k_j)}
  \]
  这里 \( q_l \) 是为层 \( l \) 学到的向量，\( k_i \) 是先前层的输出。

### 2. 块注意残差（Block Attention Residuals）

- **分区**：将层分成 **N个块**，将计算内存开销从 \( O(Ld) \) 降低到 \( O(Nd) \)。
- **块内累积**：每个块通过求和聚合其层输出，形成统一表示。
- **块间注意**：仅对块级表示进行注意，不显著影响性能的同时提高效率。
- **实现示例**：
  ```python
  def block_attn_res(blocks, partial_block, proj, norm):  
      V = torch.stack(blocks + [partial_block])  # 堆叠块表示
      K = norm(V)  # 应用归一化
      logits = torch.einsum('d, n b t d -> n b t', proj.weight.squeeze(), K)  # 计算注意力logits
      h = torch.einsum('n b t, n b t d -> b t d', logits.softmax(0), V)  # 计算最终输出
      return h  
  ```

## 好处总结

- **选择性聚合**：通过注意力机制，能够根据上下文保留或强调早期层的信息，提升模型层的有效输出。
- **减少内存开销**：块注意残差减轻了在训练过程中保持所有层输出所带来的内存负担。
- **性能提升**：实验结果显示在多个基准测试上取得了改善，确认了该方法在保持有效深度信息流的鲁棒性。

该方法为大规模模型训练提供了可行的解决方案，缓解了深度神经网络中的常见问题。

Full Attention Residuals 详细描述

1. 概念
   完整注意残差（Full AttnRes）通过学习的权重聚合先前层的输出，以替代传统的固定累积方法。这种方法允许每层根据输入动态选择先前层的输出，从而减少信息稀释，提高模型的表现。
2. 工作原理
   公式:
   \[
   h_l = \sum_{i=0}^{l-1} \alpha_{i \to l} \cdot v_i
   \]

- \( h_l \): 进入层 \( l \) 的隐藏状态。
- \( \alpha_{i \to l} \): 使用 softmax 计算的注意力权重。

3. 注意力权重计算
   权重计算公式:
   \[
   \alpha_{i \to l} = \frac{\phi(q_l, k_i)}{\sum_{j=0}^{l-1} \phi(q_l, k_j)}
   \]

- \( q_l \): 为层 \( l \) 学到的查询向量。
- \( k_i \): 对应于第 \( i \) 层输出的键向量。
  核心机制:
- 使用一个经过 RMSNorm 函数归一化的内核函数 ϕ:
  \[
  \phi(q, k) = \exp\left(q^\top \text{RMSNorm}(k)\right)
  \]

4. 输入计算
   每层的输入由以下结果计算得到：
   \[
   h_l = \sum_{i=0}^{l-1} \alpha_{i \to l} \cdot v_i
   \]
   其中 \( v_i \) 是各层的输出，可以定义为：

- 令 \( v0 = h1 \)（输入的 token 嵌入）,
- 对于 \( i \geq 1 \)，\( v_i = f_i(h_i) \)。

5. 实现示例
   以下是一个简单的 PyTorch 实现示例，展示如何在模型中集成 Full AttnRes：
   import torch
   import torch.nn as nn
   class FullAttentionResidual(nn.Module):
   def __init__(self, total_layers, hidden_dim):
   super(FullAttentionResidual, self).__init__()
   self.total_layers = total_layers
   self.hidden_dim = hidden_dim

   # 学习的伪查询向量
   self.pseudo_queries = nn.Parameter(torch.zeros(total_layers, hidden_dim))
   self.layers = nn.ModuleList([self.create_layer() for _ in range(total_layers)])
   def create_layer(self):
   # 定义层，这里可以是一个简单的线性层或任何你想要的层
   return nn.Linear(self.hidden_dim, self.hidden_dim)
   def forward(self, x):
   # 保存所有层的输出
   layer_outputs = []

   for l in range(self.total_layers):
   # 计算当前层的输出
   output = self.layers[l](x)
   layer_outputs.append(output)
   # 计算注意力权重
   attention_weights = self.compute_attention_weights(l, layer_outputs)
   # 计算当前层的最终输出
   x = sum(attention_weights[i] * layer_outputs[i] for i in range(l + 1))
   return x
   def compute_attention_weights(self, current_layer, layer_outputs):
   current_query = self.pseudo_queries[current_layer]
   # 权重计算
   weights = [torch.exp(current_query @ output) for output in layer_outputs[:current_layer + 1]]
   total_weight = sum(weights)
   return [w / total_weight for w in weights]
