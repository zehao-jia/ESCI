# 线性代数
- 向量的数乘,矩阵的内积
- 矩阵的哈达玛积:对应元素相乘
- 矩阵的克罗内克积:每个元素数乘右边的矩阵

# 矩阵的性质
- 求逆矩阵:$AB = BA = E$时,AB互为逆矩阵
- 当$A^{-1} = A^T$时,A为正交矩阵
- 特征值,特征向量
- 矩阵的秩:所有行向量线性无关的最大行数
- 矩阵的奇异值:$A^TA$的特征值$\lambda_1,\lambda_2...$,对其开根号称为矩阵的奇异值
- 矩阵的范数:可以看做向量的范数在矩阵的推广

# 概率统计
- 熵:表示随机变量中不确定度的度量
