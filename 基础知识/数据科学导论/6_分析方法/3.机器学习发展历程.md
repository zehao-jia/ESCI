# 第一阶段:推理期(20世纪50年代到60年代初)
- 思路:只要赋予机器推理能力,机器就会拥有智能
- 贝叶斯分类器
- 50年代中期,基于神经网络的"**连接主义**"学习,感知机的出现解决线性分类问题

# 第二阶段:冷静时期(20世纪60年代到70年代初)
- 仅有逻辑推理能力无法使机器拥有智能
- 基于逻辑表示的"**符号主义**"
- 最近邻算法,k均值算法

# 第三阶段:知识期(20世纪70年代中叶到80年代初)
- 人们提出要想机器拥有智能,就要让机器获得知识
- 专家系统问世,获得许多应用领域的研究成果
- 1981年,多层感知机在韦伯斯的神经网络反向传播算法(BP)中提出

# 第四阶段:学习期(20世纪80年代中期到现在)
- 由于专家系统总结知识困难,提出了让机器自主学习知识
- 基于神经网络的连接主义的主要成果:1986年用于训练多层神经网络的反向传播算法
- 1989年,第一个卷积神经网络
- 基于逻辑学习的符号主义成果:ID3决策树算法
- 二十世纪九十年代中期,统计学习的发展催生出支持向量机
- 同一时期,Adaboost代表集成学习算法,将简单的弱分类器集成,达到了惊人精度
- 21世纪至今,大数据的到来,数据量增大以及算力增强催生出深度学习
- 2006年.辛顿提出deeplearning算法使神经网络的能力大幅提升
