# Prompt 机制笔记：从 PromptIR 到高光谱油检测的适配思考

## 来源

基于 PromptIR（NeurIPS 2023）论文精读及讨论。

---

## 一、Prompt 生成的作用

### 核心直觉

全合一（All-in-One）模型需要同一套网络处理多种不同类型的退化（去噪、去雨、去雾），但每种退化需要的处理方式完全不同。Prompt 的作用是：**告诉网络当前输入是什么退化类型，让网络切换对应的处理模式。**

类比：全能医生先做检查（分析输入特征），根据检查结果选择对应科室的方案（生成对应退化类型的 prompt），然后执行治疗（prompt 引导解码器）。

### 与传统方案的区别

| 方案 | 做法 | 问题 |
|------|------|------|
| 单任务模型 | 每种退化独立训练一个模型 | 需事先知道退化类型，不实用 |
| 多分支架构 | 各分支对应一种退化 | 需退化先验 |
| PromptIR | 隐式编码退化信息 + 动态选择 | 盲复原，单阶段训练 |

## 二、Prompt 的生成方式（PGM）

### 流程

```
输入特征 F_l (H×W×C)
    ↓
全局平均池化 GAP → 向量 v (1×1×C)
    ↓
1×1 卷积降维到 N 维（N=5）
    ↓
Softmax → 权重 w ∈ [0,1]^N（和为1）
    ↓
对 N 个可学习提示组件加权求和：P = Σ w_c · P_c
    ↓
3×3 卷积变换 → 最终提示 P (H×W×C)
```

### 关键点

- **N 个可学习提示组件** P_c：随机初始化，训练过程中通过反向传播自动分化
  - 不同组件学会编码不同的退化模式（去雾、去雨、去噪等）
  - 分化是**自然涌现的**，不是人为指定的
- **权重由输入动态决定**：不同类型退化的图像经 GAP 后得到不同的全局统计特征（雾图低频、噪声图高频、雨图有周期性条纹），PGM 自动学会据此分配权重
- **消融证据**（Table 5）：
  - 无 Prompt（纯 Restormer）：36.74 dB
  - +固定提示（无 PGM，权重固定）：36.85 dB（+0.11）
  - +动态提示（完整 PGM）：**37.04 dB（+0.30）**

### PGM 与 MoE 的本质区别

| 维度 | PGM（PromptIR） | MoE + Top-K（MambaMoE） |
|------|---------------|----------------------|
| **加权对象** | 对**参数本身**加权求和（参数组合） | 对**专家的输出**加权求和（结果组合） |
| **谁在干活** | 提示组件是静态参数，不处理输入 | 每个专家是完整的处理通道，独立处理输入 |
| **与特征交互** | 加权后的提示与特征拼接，再一起过 Transformer | 每个专家独立处理特征，加权合并后输出 |
| **计算路径** | **1 条路径**（共享 Transformer Block） | **N 条路径**（N 个专家并行计算） |
| **是否有稀疏性** | ❌ 全部组件参与 | ✅ 通常仅 Top-K 激活 |
| **决策粒度** | 整张图一个权重（GAP 全局池化） | 每个像素可不同（路由网络输出空间权重） |

**本质定性**：PGM 更接近 **动态特征调制（Dynamic Feature Modulation）** 或 **条件参数生成（Conditional Parameter Generation）**，而非 MoE。

## 三、Prompt 与特征的融合方式

### 方案 A：Concat 沿通道拼接（PromptIR 原版）

```python
[F_l; P]  →  concat(dim=1)  →  MDTA + GDFN  →  Conv3×3  →  输出
```

- 特征 F_l ∈ ℝ^{H×W×C}，提示 P ∈ ℝ^{H×W×C}，拼接后通道 2C
- 让 Transformer 自己学如何融合提示和特征
- **缺点**：通道数翻倍，MDTA 复杂度 O(C²) 显著增加
- 对于高光谱数据（通道数大）尤其不友好

### 方案 B：Prompt 与 V 矩阵相乘（在 Attention 内部）

```python
V' = V ⊙ P                    # 逐元素乘法（广播）
Attention(Q, K, V') 代替 Attention(Q, K, V)
```

- Prompt 直接调制"每个位置输出什么信息"
- 放大有用通道、抑制无关通道
- **优点**：不影响通道数，改动小
- **缺点**：Q 和 K 的交互仍是盲的——Attention 矩阵不知道退化类型

### 方案 C：先逐元素相加再逐元素相乘（FiLM 式调制）

```python
F' = (F + P_add) ⊙ P_mul     # 两个独立的 prompt
# 等价于 FiLM: F' = γ ⊙ F + β
# 其中 β = P_add, γ = 1 + P_mul
```

- **加（β）**：偏置偏移，引入某种退化模式的基向量
- **乘（γ）**：缩放门控，放大有用通道、抑制无用通道
- **优点**：不影响通道数，参数量少，计算量最低
- **理论依据**：风格迁移（AdaIN）、视觉推理（FiLM）、扩散模型（Conditional Norm）中广泛验证

### 方案 D：Cross-Attention（备选）

```python
Q = F_l,  K = V = P
Output = CrossAttention(Q, K, V)
```

- 最灵活，prompt 通过 Attention 机制动态影响特征
- **缺点**：额外参数和计算量

### 四种方案对比

| 方案 | 通道数 | 参数量 | 融合灵活度 | 对高光谱友好度 |
|------|--------|--------|-----------|--------------|
| A. Concat（原版） | 翻倍 | 低 | 高（网络自学习） | ❌ 通道膨胀 |
| B. 乘 V | 不变 | 低 | 中（只调输出） | ✅ |
| C. 加+乘（FiLM） | 不变 | 低 | 中（固定模式） | ✅ |
| D. Cross-Attention | 不变 | 高 | 最高 | ✅ |

## 四、UGCL：不确定性引导的矫正学习

**来源**：MambaMoE 论文中的训练策略，与 PromptIR 的 prompt 机制无关，但可以组合使用。

### 核心直觉

模型在复杂区域（类别边界、小目标、混合像元）的预测往往不自信，但标准训练方法对所有像素一视同仁，困难区域的信号被容易像素的梯度淹没。UGCL 在解码器中间层**定位模型不自信的区域，额外提供监督信号**。

### UARB 工作流程（6 步）


```
解码器中间特征 L (H×W×C)
    ↓
① 分类头_i（1×1 conv）→ 原始分数 S
    ↓
② Softmax → 类别概率 A ∈ ℝ^{H×W×n_class}
    ↓
③ 取每个像素的最大概率 P = max_k A_k
    ↓
④ 不确定性估计 U = -log(P+ε) · P
   （P≈1 → U≈0;  P≈0.3 → U≈0.5）
    ↓
⑤ 伯努利采样：对每个像素掷骰子 r ~ Uniform(0,1)
   若 r < U，则采样该像素 (M=1)；否则跳过 (M=0)
    ↓
⑥ 采样掩码 × 真值标签 → 计算辅助交叉熵损失
   L_aux = CE(Q_i · M, A_i · M)
```

**具体演示**（以 4×4 为例）：

```
原始图像:             不确定性图 U:         采样掩码 M:
┌───┬───┬───┬───┐   ┌────┬────┬────┬────┐  ┌───┬───┬───┬───┐
│草 │草 │草 │草 │   │0.02│0.03│0.02│0.04│  │ 0 │ 0 │ 0 │ 0 │
├───┼───┼───┼───┤   ├────┼────┼────┼────┤  ├───┼───┼───┼───┤
│草 │草 │草 │建 │   │0.03│0.05│0.35│0.42│  │ 0 │ 0 │ 1 │ 1 │ ← 边界被选中
├───┼───┼───┼───┤   ├────┼────┼────┼────┤  ├───┼───┼───┼───┤
│草 │草 │建 │建 │   │0.02│0.08│0.38│0.40│  │ 0 │ 0 │ 1 │ 1 │
├───┼───┼───┼───┤   ├────┼────┼────┼────┤  ├───┼───┼───┼───┤
│路 │路 │路 │建 │   │0.04│0.06│0.45│0.50│  │ 0 │ 0 │ 1 │ 1 │ ← 道路尽头被选中
└───┴───┴───┴───┘   └────┴────┴────┴────┘  └───┴───┴───┴───┘
```

### 三个 UARB 逐步纠错

MambaMoE 在解码器的 3 个中间层各插入一个 UARB，形成**从粗到细的纠错机制**：

| UARB | 特征来源 | 特征特点 | 捕捉的错误类型 |
|------|---------|---------|--------------|
| UARB_1 | 浅层解码器 | 高分辨率，细节多 | 边界精度的局部错误 |
| UARB_2 | 中层解码器 | 中等分辨率 | 中等尺度的误判 |
| UARB_3 | 深层解码器 | 低分辨率，语义强 | 语义级别的误判 |

### 与标准深度监督（Deep Supervision）的区别

标准 UNet 只有一个最终分类头。深度监督在多个中间层加辅助分类头，但**对所有像素都算损失**。

```
标准深度监督：
L₁ → 分类头₁ → 所有像素都算交叉熵 → 辅助损失₁

UARB：
L₁ → 分类头₁ → 只选 U > 阈值（伯努利采样）的像素 → 辅助损失₁
                   ↑
             多了这一步筛选
```

### 为什么用采样而不是加权？

| | 加权法 | 伯努利采样法（UGCL） |
|---|---|---|
| 操作 | 不确定像素的损失 × 权重 | 随机抽一部分不确定像素算损失 |
| 每次结果 | 确定，反复看到同一批难像素 | 随机，每次不同像素 |
| 过拟合风险 | 高 | 低（天然正则化） |
| 梯度稳定性 | 可能被噪声污染 | 干净 |

### 三个分类头的问题

**标准 UNet 只在最后有一个分类头。UGCL 需要 3 个辅助分类头。** 这是深度监督的做法，不是标准 UNet 的做法。每个 UARB 有自己独立的分类头（1×1 conv），因为不同层的特征语义层级不同，共享分类头会互相冲突。

| UARB | L₁（浅层） | L₂（中层） | L₃（深层） |
|------|-----------|-----------|-----------|
| 特征分辨率 | 大 | 中 | 小 |
| 上采样倍数 | 小 | 中 | 大 |
| 分类头参数 | 独立的 1×1 conv | 独立的 1×1 conv | 独立的 1×1 conv |

**处理方式**：每个分类头输出对应分辨率的概率图 → 上采样到原图尺寸再算损失（与标准 UNet 最终输出前上采样逻辑一致）。

### 推理时零开销

> UARB **只在训练时激活**，推理时直接跳过。辅助分类头的参数量极小（3 个 1×1 conv，约 3.5K 参数 vs 模型 0.28M 总参数），不影响推理效率。

### UGCL 的梯度如何影响 DSSEM

关键链路：UGCL 在解码器 → 梯度经**跳跃连接（skip connection）** 回传到编码器的 DSSEM。

```
UGCL 损失
    ↓
解码器层（上采样 + 卷积）
    ↓
跳跃连接 ← 关键：直接连接到 MoMEB 的输出
    ↓
MoMEB → DSSEM 参数（SRE 路由网络 + 4 专家 SSM + SSE 双向 SSM）
```

由于跳跃连接直接将 MoMEB 输出送到解码器，UGCL 的梯度可以无损地流回 DSSEM。因为辅助损失**只采样高不确定区域**，DSSEM 的梯度更新主要由这些困难像素驱动，形成"聚光灯"效应。

### 消融证据（MambaMoE Table 1）

| 配置 | Pavia OA | 说明 |
|------|---------|------|
| 基线（无 MoMEB + 无 UARB） | 91.53 | — |
| +MoMEB | 93.86 (+2.33) | DSSEM 贡献 |
| +UARB | 92.78 (+1.25) | UGCL 独立贡献 |
| +MoMEB+UARB（完整） | **95.20 (+3.67)** | **叠加增益** |

两者结合有累积增益，说明 DSSEM 和 UGCL 的改进是互补的：DSSEM 负责"把大部分地方做好"，UGCL 负责"找到 DSSEM 还没做好的地方，逼它再学"。

## 五、Prompt 数量 N 的确定方法

### 第一步：先分析场景中有多少"变化维度"

以高光谱海面溢油检测为例：

| 变化维度 | 具体差异 | 对应 PromptIR 的"退化类型" |
|---------|---------|--------------------------|
| **油膜厚度** | 厚油层 vs 薄油膜，光谱特征不同 | 类似"退化程度" |
| **风浪条件** | 平静海面 vs 波浪海面，油膜形态不同 | 类似"退化类型" |
| **传感器类型** | 不同卫星光谱配置不同 | 类似新的"退化域" |
| **海面背景** | 清洁海水 vs 含悬浮物海水 | 干扰模式不同 |
| **油种类型** | 原油 vs 成品油，光谱特征不同 | 信号模式不同 |

### 第二步：消融实验找最优 N

```python
N_values = [1, 3, 5, 7, 10]
for N in N_values:
    model = PromptIR(N=N)
    train(model, data)
    results[N] = test(model)
best_N = argmax(results)
```

### 第三步：验证提示组件是否有效分化

用 t-SNE 可视化权重向量 w ∈ ℝ^N：

- 不同颜色的簇清晰分开 → N 合理
- 所有点混在一起 → N 太大（冗余）或太小（不够区分）

### 第四步：观察边际收益

```
N=1  → mIoU 85.2    ← 提示不够用
N=3  → mIoU 86.8    ← 够覆盖主要变化
N=5  → mIoU 87.1    ← 边际收益递减
N=7  → mIoU 86.9    ← 参数冗余甚至下降
```

选边际收益开始变平缓的那个 N。按 PromptIR 经验，N 通常在 **3~8** 之间。

### 高光谱场景的特别考虑

高光谱的**光谱维**增加了变化模式的复杂度，可能需要的 N 比自然图像更多（5~8 较合理）。但最终取决于具体数据。

## 六、总结

### 适用于高光谱油检测的建议路线

1. **N 初始设为 5**，用 t-SNE 观察分化情况
2. **融合方式选方案 C（加+乘 FiLM 式）**，对高光谱的通道数友好
3. 用消融实验确定最优 N 和最优融合方式
4. 最终验证：测试提示组件是否真的学出了可区分的"油膜状态"编码

### 关键参考

- PromptIR（NeurIPS 2023）：Concat 融合 + N=5
- FiLM（ICLR 2018）：特征级线性调制
- AdaIN（ICCV 2017）：加+乘的风格迁移范式
- MambaMoE：MoE + Top-K 的另一种路由范式（与之对比理解）
